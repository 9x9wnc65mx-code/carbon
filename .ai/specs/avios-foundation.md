# AVIOS foundation specification

AVIOS is an in-place poultry-domain adaptation of Carbon. It must preserve Carbon's authenticated ERP shell, React Router v7 conventions, `@carbon/react` UI, Lingui localization, Supabase/Postgres multi-tenancy, permissions, QMS, inventory, purchasing, workflows and traceability primitives.

The foundation establishes Arabic/RTL support and a Carbon-native Poultry Operations module. It does not introduce a parallel UI shell.
